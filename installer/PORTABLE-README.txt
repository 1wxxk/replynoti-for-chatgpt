ReplyNoti Portable - Windows 11 x64 / Windows 11 x64 전용

ENGLISH
1. Extract the entire ZIP to a writable folder.
2. Run Start-Portable.exe. It registers Windows notification identity, a Start menu shortcut and a local protocol for click-to-open, then starts the watcher. No application files are copied to Program Files or AppData.
3. Use the tray icon to open Settings. Settings and custom assets stay in this folder. Start with Windows is optional.
4. Before moving or deleting the folder, run Unregister-Portable.exe. It stops the watcher and removes the registrations, preserving files and settings.
5. Do not register the installed and portable versions simultaneously. Remove/unregister the other copy first.

The modern settings window requires Microsoft Edge WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/
Unsigned experimental beta. Windows may warn or block execution. Verify SHA256SUMS.txt and follow your organization's security policy. Never disable security protections.
Reply previews are enabled by default; they may appear on the lock screen and in notification history. Disable previews for sensitive conversations.
